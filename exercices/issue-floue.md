# Exercice - Une issue floue (étape 4)

Nadia, qui teste Trackr pour l'équipe, a posté ce message sur le canal du projet :

> la recherche marche pas avec mon numéro, j'ai le colis du casque et il le trouve pas. c'est urgent svp

Ce qu'on sait en plus (elle l'a dit à l'oral) :

- Elle a recopié le numéro tel qu'il est imprimé sur le bon de dépôt Colissimo : `FR 123 456 789`.
- Elle utilise Firefox sur Windows.

## Votre travail

1. Reproduisez le problème sur votre poste (`npm run dev`).
2. Ouvrez une issue dans votre dépôt avec le gabarit **Signaler un bug**.
3. Un nouveau venu doit pouvoir reproduire le bug et savoir quand il est corrigé, sans poser de question.
